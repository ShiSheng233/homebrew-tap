# ShiSheng233 Homebrew Tap

```sh
brew install --cask shisheng233/tap/transcriber
```

| Cask | App |
| --- | --- |
| `transcriber` | [Transcriber](https://github.com/ShiSheng233/Transcriber): generate, edit and translate subtitles with Whisper models (Apple Silicon, macOS 15+) |

Casks are updated by `make release-publish` in the Transcriber repository.
